# WorkBuddy 编程闯关教程 · 柔和数码风（雾面玻璃蓝）

一个纯静态网站，无框架、无构建、无后端。双击 `index.html` 就能在浏览器里打开。

> **只想改文字？** 看 [`文案修改指南.md`](./文案修改指南.md)——每个页面每处文案在哪个文件、搜什么关键词能找到，都列好了。

**教程主线**：教学生由浅入深地用 WorkBuddy 完成编程任务，重点覆盖 **执行模式 / 上下文管理 / Skill / 插件连接器 / MCP / 专家团**。

**分工**：这个站只负责「看懂」——讲清每个能力是什么、什么时候用、能力之间什么关系。真正动手跑任务在实践页（首页「我要上手」），那是 V2 的内容，现在预留留空。

## 怎么手动添加截屏（你只需要做这一件事）

每个截屏位都是占位框，框上写着它要的文件名。

1. 截图存成 **PNG**；
2. 按框上标注的名字命名（例如 `6-1.png`）；
3. 丢进 `assets/screens/`；
4. 刷新页面 —— 占位框自动换成你的图，**不用改任何代码**。

图片不存在时显示虚线占位框，不会变成裂图。

## 你自己能改什么（不用找我）

### 一档：改一个值，全站跟着变

全部在 `assets/css/style.css` 顶部的 `:root` 里，改右边的色值即可，不用动别的地方。

| 变量 | 现在的值 | 改了会变什么 |
|---|---|---|
| `--brand` | `#2F7DA8` | 主色：按钮、编号徽章、链接、目录高亮、进度条 |
| `--brand-dk` | `#24607F` | 主按钮的渐变深端，跟 `--brand` 一起换 |
| `--accent` | `#E8913C` | 琥珀强调色：实践区、WARN 提示框、路线图终点站 |
| `--bg` | `#EEF2F7` | 页面底色 |
| `--ink` | `#2C3A47` | 正文主文字色 |
| `--r` | `12px` | 全站圆角。想更硬朗改 `4px`，想更圆改 `20px` |
| `--mono` | `'JetBrains Mono',...` | 等宽字体（编号、代码、徽章） |
| `--sans` | `'PingFang SC',...` | 正文中文字体 |

几个单点小调整：

- **网格底纹大小**：`.grid-bg` 里的 `background-size:28px 28px`，想更密改 `16px`，更疏改 `48px`。
- **网格默认关掉**：把 `assets/js/app.js` 里 `GRID: ON` 那两个地方改成 `GRID: OFF`，并给 `body` 加上 `class="no-grid"`。
- **首页打字机那句话**：`assets/js/app.js` 里搜 `var text =`，把引号里的字换掉。
- **光标闪烁快慢**：CSS 里 `.caret` 的 `animation:blink 1.1s`，数字越小闪得越快。

### 二档：改文案（找到那一段字，直接替换）

| 想改什么 | 去哪个文件 | 搜什么关键词 |
|---|---|---|
| 首页顶部徽章、大标题、副标题 | `index.html` | `class="hero"` |
| 两个主按钮的标题和副标题 | `index.html` | `我要看书` / `我要上手` |
| FAQ 六个问题 | `index.html` | `class="faq-list"` |
| 页脚三组链接 | `index.html` | `class="f-col"` |
| 实践页标题和说明 | `practice.html` | `prac-title` / `prac-desc` |
| 章节正文（导语/要点/提示框/自检） | `assets/js/chapters.js` | 按章节号找，如 `id:'6.1'` |

FAQ 增删很自由：整段 `<details class="faq">...</details>` 复制一份改文字即可，想让哪条默认展开就给它加 `open`（现在只有 Q1 有）。

### 三档：加东西

- **加截屏**：截图存成 PNG，按占位框上标的名字命名，丢进 `assets/screens/`。刷新即可，不用改代码。
- **加一整章**：在 `assets/js/chapters.js` 里复制任意一个 `{ id:'x.x', ... }` 块，改掉编号和内容。**目录、搜索、进度条、首页路线图、侧边栏计数会自动更新**，HTML 一个字都不用动。
- **加一个新关卡**：复制一个 `{ num:'Sx', name:'...', desc:'...', chapters:[...] }` 块。
- **给某章加示例代码块**：在该章里加一个 `code` 字段，格式：
  ```js
  code:{ title:'PROMPT  ·  标题', lines:[
    ['第一行', 'cmd'],     // cmd=命令色  out=输出色  cmt=注释色
    ['第二行', 'out']
  ]},
  ```
- **首页加第三个按钮**：复制 `cta-row` 里任意一个 `<a class="btn ...">` 块，改文案和 `href`。

### 别碰这些（改了会坏）

- **`id="..."` 属性**：`toc` / `roadmap` / `chapterView` / `searchInput` / `statTotal` / `sbMeta` / `gridToggle` / `typeTarget` 等，JS 靠它们找元素，改名或删除会导致功能失效。
- **`<body data-page="...">`**：决定首页/教程页/实践页跑哪段脚本，改了页面就不渲染了。
- **章节 `id` 不能重号**：重号会导致目录跳转串章。
- **`shots` 文件名必须以 `.png` 结尾**：否则自动替换逻辑不认。
- **`assets/js/app.js` 的渲染逻辑部分**：改文案可以，改函数结构容易整页白屏。

### 改完没反应？

- 浏览器缓存：按 **Ctrl + F5** 强制刷新。
- 想清空学习进度重新来：浏览器按 F12 → Application（应用）→ Local Storage → 找到 `wb-quest-done` 删掉；或者干脆用无痕窗口打开，进度天然是空的。

## 章节数据字段说明

改 `chapters.js` 时可用的字段：

```
id       章节号（同时是 URL hash）
t        标题
min      预计分钟
level    难度：入门 / 核心 / 进阶
goal     本章目标（正文顶部绿色 GOAL 框）
lead     导语
points   要点（编号列表）
code     { title, lines:[[文本, cmd|out|cmt]] }  示例提示词 / 配置片段，带 COPY 按钮
callouts [[tip|warn|bug, 文本]]  提示框
shots    [[文件名, 说明]]  第一个是主截屏位，其余显示在「补充截屏位」
checks   理解自检（认知型条目，可勾选，不是动手任务）
```

## 关于风格

上一版是 CRT 终端荧光绿（强扫描线、直角、硬阴影）。这一版换成柔和数码风：浅灰蓝底 + 极淡 28px 网格 + 两团柔光、半透明毛玻璃卡片、12px 圆角、柔和投影、深色代码块做对比。数码感来自等宽字体、编号徽章、网格底纹和终端式代码块，不靠刺眼荧光。
