# WorkBuddy 编程闯关教程 

一个纯静态网站，无框架、无构建、无后端。双击 `index.html` 就能在浏览器里打开。

**教程主线**：教学生由浅入深地用 WorkBuddy 完成编程任务，重点覆盖 **执行模式 / 上下文管理 / Skill / 插件连接器 / MCP / 专家团**。

**分工**：教程页负责「看懂」——讲清每个能力是什么、什么时候用、彼此什么关系；实践页负责「做过」——首页点「我要上手」进去，跟着 9 章真做一只随机走动的像素猫。两边可以随时互跳，看懂了就去动手，卡住了就回来翻。

## 在线访问

* **已发布站点**：https://coding-quest.app.workbuddy.host/ （任意浏览器直接打开，无需登录、无需安装）
* **本地预览**：双击 `index.html` 即可，不需要起服务器、不需要构建

## 页面跳转

    index.html
     ├── 我要看书（先学一学） ──▶ tutorial.html
     └── 我要上手（实践出真知）──▶ practice.html（像素猫实战）

教程页用 URL hash 定位章节，例如 `tutorial.html#6.1` 直接打开 6.1 章；首页路线图和页脚链接都是这样跳转的。实践页同理，如 `practice.html#2.2`。

## 闯关路线（序章 + 9 关 · 22 章 · 约 193 分钟）

| 关卡  | 主题  | 章节  | 覆盖的能力点 |
| --- | --- | --- | --- |
| **S0 开始之前** | 站点导览、学前准备 | 0.1 – 0.2 | 怎么用这个站 / 环境要求 |
| S1 认识它 | 它是谁、界面与工作区 | 1.1 – 1.2 | 建立正确预期 |
| **S2 执行模式** | 三种模式怎么选、权限确认与升级时机 | 2.1 – 2.2 | **执行模式**（前置，先划安全边界） |
| S3 会提问 | 好任务四件套、给上下文、追问纠偏 | 3.1 – 3.3 | 提示词基本功 |
| **S4 上下文管理** | 喂什么忘什么、长任务不跑偏 | 4.1 – 4.2 | **上下文管理**（紧跟提问） |
| S5 装能力 | Skill 是什么、自己写一个、该不该写 | 5.1 – 5.3 | **Skill** |
| S6 接外援 | 先讲区别、插件连接器、MCP 配置、MCP 场景 | 6.1 – 6.4 | **插件连接器 + MCP** |
| S7 安全边界 | 权限、数据与红线 | 7.1 | 安全收口 |
| S8 团队作战 | 专家团是什么、该请谁 | 8.1 – 8.2 | **专家团** |
| S9 出发去实践 | 下一步去实践课 | 9.1 | 推向实践区 |

**编排逻辑**：先划它能碰什么（模式）→ 学会跟它说话（提问）→ 管住喂进去的东西（上下文）→ 装本地能力（Skill）→ 接外部能力（插件/MCP，由轻到重）→ 收口安全 → 组合技（专家团）→ 推向实践。

## 关于风格

上一版是 CRT 终端荧光绿（强扫描线、直角、硬阴影）。这一版换成柔和数码风：浅灰蓝底 + 极淡 28px 网格 + 两团柔光、半透明毛玻璃卡片、12px 圆角、柔和投影、深色代码块做对比。数码感来自等宽字体、编号徽章、网格底纹和终端式代码块，不靠刺眼荧光。实践页复用同一套骨架，只通过覆盖一组品牌色变量切换成橙色主题。
